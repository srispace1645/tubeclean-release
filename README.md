# TubeClean downloads

YouTube without ads, in guest mode, with no watch history kept. Runs on Fire TV, Google TV / Android TV and Android phones.

**Latest version:** [TubeClean.apk](https://github.com/srispace1645/tubeclean-release/releases/latest/download/TubeClean.apk)

**Install guide:** https://srispace1645.github.io/tubeclean-release/ (Fire TV, Google TV / Android TV and Android phones). The guide is `index.html` in this repository: edit it here on GitHub and the page updates about a minute later.

This repository only holds release builds and the install guide, and isn't affiliated with YouTube, Google or Amazon.
